MVP Feature Map

Confirm what's in. Everything else goes to Phase 2.

Module 1 — Data Pipeline
  • Scrape RBI, SEBI, IRDAI, MCA on a configurable schedule
  • Deduplicate, extract text from PDFs
  • Store in DB (PostgreSQL) per org
  • Admin can set fetch frequency (hourly / every 6h / daily)
Module 2 — AI Analysis Engine
  • Summary — 3–5 sentence plain English summary
  • Applicability — Does this apply to your org? Why?
  • Conclusion — What does this mean for you?
  • Action Items — What to do, suggested owner, by when
  • Powered by Ollama/Llama locally (upgradeable)
Module 3 — Dashboard
  • Live feed of regulatory updates
  • Filter by regulator, document type, risk level, date
  • Per-update expandable card with full AI analysis
  • Mark as reviewed / assign to team member
  • Summary metrics (total today, high risk, unreviewed)
Module 4 — Daily Email Digest
  • One email every morning at configurable time
  • Groups updates by Regulator → Document Type
  • Each item: summary + applicability + action items
  • Links to full analysis in dashboard
  • Configurable recipient list per org
Module 5 — Org Onboarding
  • Structured profile: NBFC type, product lines, AUM, geography
  • Optional document upload (RBI certificate, compliance manual)
  • Admin creates org manually (no self-serve for MVP)
  • Single login per org for MVP
Phase 2 (not in MVP)
  • AI Query Assistant ("Is this allowed?")
  • Multi-user + role management
  • Self-serve signup + billing
  • Audit trail / compliance log export
  • Custom source configuration

Does this feature set look right? Any module you want to add, remove, or change?
